# Sheikh Md. Tahmid Ullah — Academic Portfolio

Live website URL (GitHub Pages): **https://tahmidsk.github.io**

Static academic portfolio tailored for PhD and graduate study abroad applications in Genetic Engineering, Biotechnology, Microbial Genomics, Metagenomics, and Antimicrobial Resistance.

## Structure

- `index.html` — Semantic single-page academic profile with Schema.org metadata and Open Graph tags.
- `styles.css` — Responsive light/dark editorial academic stylesheet and print stylesheet.
- `script.js` — Theme persistence, mobile drawer, section scroll spy, research category filtering, expandable certifications, and clipboard copy helpers.
- `assets/profile.jpg` — Optimized headshot portrait (`640x810`).
- `assets/CV_Sheikh_Md_Tahmid_Ullah.pdf` — Downloadable full academic CV.
- `assets/og-preview.png` & `assets/favicon.svg` — Social sharing preview card and site icon.

## How to Update

1. **Edit profile text, publications, or awards:** Update `index.html` directly.
2. **Update downloadable CV:** Replace `assets/CV_Sheikh_Md_Tahmid_Ullah.pdf` (keeping the same filename).
3. **Update portrait photo:** Replace `assets/profile.jpg`.
4. **Publish changes:**
   ```bash
   git add .
   git commit -m "Update academic portfolio"
   git push origin main
   ```
   GitHub Pages automatically rebuilds and publishes updates to `https://tahmidsk.github.io` within 1–2 minutes.
